# Kasa

Refonte du front-end de la plateforme de location d’appartements Kasa, développée avec React.

Le projet consiste à créer une application web moderne, responsive et interactive à partir de maquettes Figma, en utilisant React et React Router.

Les données des logements sont simulées à partir d'un fichier JSON.

## 🛠️ Technologies utilisées

- React
- React Router
- JavaScript
- Vite
- Sass
- CSS
- JSON
- Git / GitHub

## ✨ Fonctionnalités

- Affichage dynamique des logements à partir de données JSON
- Navigation entre les pages avec React Router
- Pages détaillées pour chaque logement
- Composants React réutilisables
- Galerie d'images avec navigation précédent / suivant
- Navigation circulaire dans la galerie
- Composants Collapse avec animation CSS
- Interface responsive adaptée aux différents écrans
- Intégration des maquettes Figma

## 💡 Compétences développées

- Création et organisation de composants React
- Mise en place du routage avec React Router
- Gestion et affichage de données JSON
- Création de composants réutilisables
- Utilisation de Sass
- Création d'animations CSS
- Intégration de maquettes Figma
- Développement responsive
- Structuration d'une application React avec Vite
